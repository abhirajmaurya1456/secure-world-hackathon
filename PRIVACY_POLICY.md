# PhishGuard Privacy Policy

**Last updated:** September 27, 2026

PhishGuard is a browser extension that analyzes website URLs to identify potential phishing and security risks.

## Information We Process

When PhishGuard analyzes a URL, the URL is sent to the PhishGuard backend for security analysis. The backend processes the URL using machine-learning models, deterministic security rules, and known-domain context.

PhishGuard does not require users to create an account.

## What We Do Not Collect

PhishGuard does not intentionally collect:

* passwords or authentication credentials
* payment information
* personal profile information
* browsing history as a separate database
* webpage contents, form contents, or keystrokes

The extension stores temporary analysis results and navigation state locally in Chrome using extension storage.

## How URLs Are Used

URLs are used only to perform the requested phishing-risk analysis and return a security verdict such as SAFE, SUSPICIOUS, or PHISHING.

PhishGuard does not sell users' URL data or use it for advertising.

## Third-Party Services

PhishGuard uses a cloud-hosted backend provided through Render to process URL analysis requests.

## Data Security

PhishGuard uses HTTPS when communicating between the browser extension and the deployed backend.

No system can guarantee that every phishing or malicious URL will be detected. PhishGuard is intended as a security-assistance tool and should not be treated as a complete security guarantee.

## Changes to This Policy

This privacy policy may be updated when PhishGuard's data handling or functionality changes.
